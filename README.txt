RESTAURANT STARTER PACK

Merci pour votre achat !

CONTENU DU PACK
- index.html : structure du site
- style.css : design et mise en page
- script.js : fonctionnalités interactives
- images/ : images du restaurant et des plats

INSTALLATION
1. Extrayez les fichiers si nécessaire.
2. Ouvrez index.html dans votre navigateur.
3. Modifiez les textes, les prix et les images.
4. Dans index.html et script.js, remplacez le numéro WhatsApp
   par celui de votre restaurant.

PERSONNALISATION
Vous pouvez modifier les couleurs, le nom du
restaurant, le menu et les coordonnées.

Besoin d'aide ? Contactez le vendeur.

Merci et bonne utilisation !
